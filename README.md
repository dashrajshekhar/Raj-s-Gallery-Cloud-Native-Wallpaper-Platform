# Raj-s-Gallery-Cloud-Native-Wallpaper-Platform
A cloud-native, full-stack wallpaper gallery platform built with vanilla JavaScript &amp; Supabase — featuring admin-gated uploads, AI wallpaper generation (Flux/Pollinations), real-time cloud sync, and HD downloads. Deployed on Netlify CDN. No frameworks. No backend servers.

# Raj's Gallery 🖼️

A cloud-native, full-stack wallpaper distribution platform built with vanilla JavaScript and Supabase.

## 🔗 Live Site
[gallerybyraj.netlify.app](https://gallerybyraj.netlify.app)

## 🛠️ Tech Stack
- HTML, CSS, Vanilla JavaScript
- Supabase (PostgreSQL + Object Storage)
- Pollinations AI (Flux model)
- Netlify CDN

## ✨ Features
- Browse & download wallpapers across 10 categories
- Admin-protected uploads with password gate
- Multi-file cloud upload via REST API
- AI wallpaper generator with style presets
- Real-time download counter tracked in PostgreSQL
- Fully responsive dark navy & gold UI
